# Home Assistant - Redodo MPPT

Native Home Assistant integration for Redodo MPPT Solar Charge Controllers.

## Features

- RS485 / Modbus RTU
- Local polling
- Battery
- PV
- Load
- Today statistics
- Total statistics
- Battery settings
- Load settings
- LiFePO4 support

## Supported Controllers

- ROCC1210
- ROCC1220
- ROCC2410
- ROCC2420
- ROCC2430
- ROCC2440
- ROCC4840
